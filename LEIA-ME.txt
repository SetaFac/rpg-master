RPG MASTER — MESA ONLINE
=========================

O QUE É
  O mestre liga um pequeno servidor no próprio PC. Os jogadores se conectam
  pelo endereço dele e veem o mapa, movem os personagens que o mestre liberar,
  conversam e rolam dados no chat. Funciona em rede local ou por VPN
  (Radmin VPN, Hamachi, ZeroTier, Tailscale…).

PASSO A PASSO — MESTRE
  1. Instale o Node.js (gratuito, versão LTS): https://nodejs.org
  2. Deixe estes arquivos juntos na mesma pasta:
        RPG-Master.html   servidor.js   Iniciar-Servidor.bat
  3. Dê dois cliques em Iniciar-Servidor.bat (Windows) ou rode
     "node servidor.js" (Mac/Linux). Se o Windows perguntar sobre o Firewall,
     clique em "Permitir acesso".
  4. A janela mostra a CHAVE DO MESTRE e os ENDEREÇOS (ex.: http://26.1.2.3:3000).
     Se usa Radmin VPN, o endereço que começa com 26. é o que seus amigos usam.
  5. No RPG Master: Mesa virtual > botão 🌐 Online > cole o endereço
     (ou http://localhost:3000) e a chave > Conectar.
  6. Clique num token > "Controlado por" > escolha o jogador (ou "Qualquer jogador").

PASSO A PASSO — JOGADORES
  1. Entrem na mesma rede VPN do mestre (ex.: Radmin VPN, com a rede e a senha
     que o mestre passar).
  2. Abram o RPG Master (o mesmo arquivo .html de sempre) >
     "Entrar numa mesa online" > endereço que o mestre passou + seu nome.
  3. Movam só os personagens liberados. Rolagens de dados vão para o chat.
  (Alternativa: abrir o endereço do mestre direto no navegador. Mas as fichas
   ficam guardadas por endereço; quem usa o arquivo .html mantém as suas.)

OPÇÕES DO SERVIDOR
  node servidor.js --porta 3000 --chave minhachave --senha segredo
     --senha  exige que os jogadores digitem uma senha para entrar.

O QUE OS JOGADORES VEEM
  Só o que está visível: o que está sob névoa e os itens/tokens "ocultos"
  nunca são enviados a eles. Efeitos e ambientes do painel de som podem tocar
  para eles (opção no diálogo Online). Músicas do seu computador NÃO são
  transmitidas; use a call de voz (Discord) para isso.

CUIDADOS
  - O servidor é para jogar entre amigos. Não abra a porta para a internet
    inteira sem VPN. A chave do mestre só vale enquanto o servidor estiver ligado.
  - Se o mestre fechar a janela do servidor, a mesa cai (o mapa continua salvo
    no navegador do mestre).
  - Feche o servidor com Ctrl+C quando acabar a sessão.
